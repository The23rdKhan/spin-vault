## 📸 Screenshots - Just Run the App!

**You need to actually run the app and capture:**

```bash
# iOS Simulator
npm run ios
# Press Cmd + S to screenshot

# Android Emulator
npm run android
# Click camera icon in toolbar
```

**Capture these screens:**
1. Main slot machine with big win
2. Win celebration modal
3. Profile screen with achievements
4. Shop screen with coin packages
5. Daily bonus modal
6. Events screen

## 🎬 Quick Video Recording

### iOS Simulator (macOS):
```bash
xcrun simctl io booted recordVideo preview.mp4
# Play through app for 20 seconds
# Press Ctrl+C to stop
```

### iPhone:
- Enable: Settings → Control Center → Screen Recording
- Record 20 seconds of gameplay
- AirDrop to computer

1. **App Icons** (1 hour) - Use AI generation prompts above
